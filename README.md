# Estudos de Maratona de Programação — ESPM

Repositório colaborativo de estudos para alunos da **ESPM** interessados em programação competitiva e na **Maratona de Programação da SBC**.

O objetivo é reunir materiais, códigos, exercícios e referências que ajudem estudantes a desenvolver raciocínio algorítmico, aprender estruturas de dados e se preparar para competições — desde os primeiros problemas até conteúdos mais avançados.

> Este é um projeto independente criado por estudantes e não representa um repositório oficial da ESPM.

## Para quem é este repositório?

Este material é indicado para alunos da ESPM que:

- querem conhecer a programação competitiva;
- estão começando a resolver problemas em juízes on-line;
- desejam participar dos treinamentos e formar uma equipe;
- pretendem representar a ESPM na Maratona de Programação;
- buscam revisar algoritmos e estruturas de dados por meio da prática.

Não é necessário ter experiência prévia com competições. Conhecimentos básicos de lógica de programação já são suficientes para começar.

## O que você encontrará aqui

O repositório poderá reunir:

- materiais introdutórios sobre programação competitiva;
- explicações de algoritmos e estruturas de dados;
- códigos de referência e templates para competição;
- listas de exercícios organizadas por assunto e dificuldade;
- soluções comentadas de problemas selecionados;
- estratégias de estudo, treino em equipe e preparação para contests;
- referências externas úteis para aprofundamento.

## Trilha de estudos sugerida

### 1. Fundamentos

- entrada e saída;
- condicionais e laços;
- funções;
- vetores, matrizes e strings;
- ordenação e busca;
- análise básica de complexidade.

### 2. Estruturas de dados

- pilha, fila e deque;
- `set`, `map` e tabelas de frequência;
- fila de prioridade;
- soma de prefixos;
- estruturas para conjuntos disjuntos (DSU).

### 3. Técnicas de resolução

- força bruta;
- algoritmos gulosos;
- busca binária;
- dois ponteiros e janela deslizante;
- recursão e backtracking;
- programação dinâmica.

### 4. Grafos e tópicos avançados

- busca em largura (BFS) e busca em profundidade (DFS);
- ordenação topológica;
- caminhos mínimos;
- árvore geradora mínima;
- teoria dos números;
- combinatória;
- algoritmos de strings.

## Como estudar com este repositório

1. Escolha um assunto compatível com o seu nível atual.
2. Estude o conceito e implemente o algoritmo sem copiar a solução pronta.
3. Resolva primeiro problemas introdutórios e aumente a dificuldade gradualmente.
4. Se travar, registre o que tentou antes de consultar uma explicação.
5. Após resolver, compare abordagens e analise a complexidade da solução.
6. Refaça problemas importantes depois de alguns dias.
7. Participe de contests e treinos em equipe para praticar sob limite de tempo.

O foco não deve ser apenas acumular exercícios resolvidos, mas aprender a reconhecer padrões e justificar por que uma solução funciona.

## Plataformas recomendadas

- [NEPS Academy](https://neps.academy/) — conteúdo em português e exercícios organizados por dificuldade;
- [beecrowd](https://beecrowd.com.br/) — problemas introdutórios e clássicos de competições;
- [Codeforces](https://codeforces.com/problemset) — contests frequentes e problemas classificados por dificuldade;
- [CSES Problem Set](https://cses.fi/problemset/) — coleção estruturada de problemas clássicos;
- [Maratona de Programação da SBC](https://maratona.sbc.org.br/) — informações sobre a competição brasileira.

## Provas para treinar

As provas anteriores são uma boa forma de simular uma competição real, praticar a divisão de problemas entre os integrantes da equipe e identificar os assuntos que precisam ser revisados.

### Maratona de Programação da SBC — Fase Regional

- [Fase Regional 2024](https://codeforces.com/gym/105327)
- [Fase Regional 2025](https://codeforces.com/gym/106073)

### Maratona Paulista de Programação

- [I Maratona Paulista de Programação — 2025](https://codeforces.com/gym/105904)
- [II Maratona Paulista de Programação — 2026](https://codeforces.com/gym/106598)

Para uma simulação completa, reúna uma equipe de até três pessoas, escolha apenas uma máquina e reserve cinco horas para resolver a prova. Evite consultar soluções, editoriais ou códigos externos durante o treino. Ao terminar, faça um *upsolving*: retome os problemas não resolvidos, estude as abordagens necessárias e registre os principais aprendizados.

## Linguagem recomendada

Os materiais podem abordar diferentes linguagens, mas **C++** é recomendada para competições por sua eficiência e pela ampla biblioteca de algoritmos e estruturas de dados disponível na STL.

Exemplo de template inicial:

```cpp
#include <bits/stdc++.h>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    return 0;
}
```

## Como contribuir

Contribuições de estudantes da ESPM são bem-vindas. Você pode colaborar com:

- novos materiais e listas de exercícios;
- soluções explicadas;
- correções de código ou documentação;
- sugestões de trilhas e plataformas;
- relatos e aprendizados de treinos e competições.

Antes de enviar uma contribuição, verifique se o código está legível, se a complexidade foi informada quando relevante e se a solução não contém dados pessoais ou conteúdo protegido de competições em andamento.

## Objetivo da iniciativa

Além de apoiar o desenvolvimento individual, este repositório busca fortalecer a comunidade de programação competitiva da ESPM, facilitar a entrada de novos estudantes e preservar materiais que possam ajudar as próximas equipes da instituição.

Se você é aluno da ESPM e tem interesse em participar, comece pela trilha básica, pratique com consistência e compartilhe o que aprender.
